# 🎓 ระบบติดตามคะแนน การส่งงาน และการเข้าเรียน (Smart Gradebook & Classroom Tracker)

เว็บแอปพลิเคชันสำหรับอาจารย์ผู้สอนหลายวิชาและหลายห้องเรียน รองรับการซิงค์ข้อมูลกับ **Google Sheets** ใช้งานได้หลายอุปกรณ์พร้อมกัน และมีหน้าสำหรับให้นักเรียนเข้ามาเช็คคะแนน/งานค้างของตัวเองโดยไม่สามารถแก้ไขข้อมูลได้

---

## ✨ ฟีเจอร์หลักของระบบ

1. **📊 หน้า Dashboard ภาพรวมทุกรายวิชาและห้องเรียน**
   - ดูสถิติภาพรวมทุกวิชา หรือเลือกกรองเฉพาะวิชาและห้องเรียนที่ต้องการ
   - กราฟแสดงการกระจายเกรด **8 ระดับ (A, B+, B, C+, C, D+, D, F)**
   - รายชื่อแจ้งเตือนนักเรียนที่มี **งานค้างส่ง** หรือ **เสี่ยงติด F** อัตโนมัติ

2. **📝 ตารางกรอกคะแนน & ติดตามการส่งงาน & ตัดเกรดอัตโนมัติ**
   - กรอกคะแนนงานย่อย, รายงาน, สอบกลางภาค, สอบปลายภาค และคะแนนจิตพิสัย/อื่นๆ
   - เลือกสถานะการส่งงาน (`✓ ส่งแล้ว`, `⏱ ส่งช้า`, `✗ ค้างส่ง`)
   - คำนวณคะแนนรวมและตัดเกรด **A, B+, B, C+, C, D+, D, F** ทันทีที่พิมพ์คะแนน
   - รองรับการ **ก๊อปปี้รายชื่อนักเรียนจาก Excel หรือ Google Sheets** มาวางทีละทั้งห้องเรียน
   - ส่งออกตารางคะแนนเป็นไฟล์ `.CSV` (เปิดด้วย Excel ได้ทันที รองรับภาษาไทย 100%)

3. **📅 ระบบเช็คชื่อและคำนวณคะแนนเข้าเรียนอัตโนมัติ**
   - เลือกวันที่เรียน และกดเช็คชื่อ (`มาเรียน`, `มาสาย`, `ลา`, `ขาดเรียน`) หรือกดปุ่ม **"เช็คมาเรียนทั้งหมด"** ในคลิกเดียว
   - คำนวณเปอร์เซ็นต์การเข้าเรียนและแปลงเป็นคะแนนเข้าเรียนตามสัดส่วนของวิชานั้นอัตโนมัติ

4. **🔍 ดูรายละเอียดคะแนนรายบุคคล (Student Individual Profile)**
   - คลิกที่ชื่อนักเรียนคนใดก็ได้เพื่อดูกราฟสัดส่วนคะแนนแต่ละหมวด ประวัติการเข้าเรียน รายการงานค้าง และสั่งพิมพ์ใบสรุปผลรายบุคคล (Print / PDF)

5. **🧑‍🎓 หน้าสำหรับนักเรียนเช็คคะแนนและงานค้าง (ดูได้อย่างเดียว แก้ไขไม่ได้)**
   - นักเรียนกรอกเฉพาะ **รหัสนักเรียน** เพื่อดูคะแนนทุกวิชาที่ตัวเองเรียน งานที่ค้างส่ง และเกรดปัจจุบัน
   - ป้องกันการแก้ไขด้วยรหัสผ่านอาจารย์ (PIN) ทั้งบนหน้าเว็บและตรวจสอบซ้ำในฝั่ง Google Apps Script

## 🔗 วิธีเชื่อมต่อกับ Google Sheets (ทำครั้งเดียว ใช้งานได้ทุกอุปกรณ์)

1. เปิด Google Drive ของอาจารย์ แล้วสร้างไฟล์ **Google Sheets** ใหม่ 1 ไฟล์
2. ไปที่เมนูด้านบน **ส่วนขยาย (Extensions) > Apps Script**
3. เปิดไฟล์ [`google-apps-script/Code.gs`](file:///g:/ไดรฟ์ของฉัน/took/google-apps-script/Code.gs) คัดลอกโค้ดทั้งหมดไปวางแทนที่โค้ดเดิมใน Apps Script แล้วกดบันทึก (💾)
4. กดปุ่มสีน้ำเงินมุมขวาบน **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
5. คลิกไอคอนรูปเฟือง เลือกประเภทเป็น **เว็บแอป (Web app)** และตั้งค่าดังนี้:
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`
6. กด **ทำให้ใช้งานได้ (Deploy)** แล้วกดอนุญาตสิทธิ์ (Authorize access)
7. คัดลอก **URL ของเว็บแอป (Web App URL)** มาวางในหน้าเว็บแอปของอาจารย์ (ปุ่ม **"🔗 ตั้งค่าเชื่อม Sheet / ลิงก์นักเรียน"** มุมขวาบน) แล้วกดบันทึก!
   - ระบบจะสร้างแผ่นงาน (Sheet Tabs) แยกตามรายวิชาและตารางสรุปเกรดรวมใน Google Sheets ให้อัตโนมัติทันที
